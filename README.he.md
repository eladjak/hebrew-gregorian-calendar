# לוח שנה עברי-גרגוריאני

יישום לוח שנה המשלב לוח שנה עברי וגרגוריאני, מבוסס React.

## תכונות

- מעבר בין תצוגת לוח עברי וגרגוריאני
- הוספה, עריכה ומחיקה של אירועים
- תצוגת חודש, שבוע, יום ורשימה
- עיצוב רספונסיבי
- תמיכה בחגים ומועדים

## טכנולוגיות

- React
- JavaScript
- CSS

## התקנה

```bash
git clone https://github.com/eladjak/hebrew-gregorian-calendar.git
cd hebrew-gregorian-calendar
npm install
npm start
```
